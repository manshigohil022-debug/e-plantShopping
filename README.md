# e-plantShopping

## Project Overview

**e-plantShopping** is a React-based web application for an online plant shopping experience. The application allows users to browse different types of plants, view product details, add plants to a shopping cart, and manage their purchases through a simple and user-friendly interface.

### Features

* Browse a variety of plants
* View plant details
* Add and remove items from the shopping cart
* Responsive and user-friendly design
* Built using React and modern web technologies

### Technologies Used

* React
* JavaScript
* HTML
* CSS
